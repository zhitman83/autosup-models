# autosup-models

Модели распознавания речи для приложения **AutoSup** — раздаются готовыми
файлами через GitHub Releases.

## Зачем отдельный репозиторий

Файлы моделей весят десятки мегабайт и обновляются своим ритмом. Держать их
рядом с сайтом (`autosup-web`) нельзя: там лежит рабочая инфраструктура —
AASA-файл для universal links, политика приватности и страница удаления
аккаунта, то есть требования App Store и Google Play. Любая неприятность с
раздачей больших файлов не должна задевать эти страницы.

Код приложения живёт отдельно и остаётся закрытым. Здесь — только сторонние
модели и документы их лицензий.

## Что здесь лежит

| Релиз | Модель | Язык | Размер |
|---|---|---|---|
| `whisper-kk-v1` | whisper-base.kk (GGML, квантованная) | казахский | ~57 МБ |

Файлы прикладываются к релизам, а **не коммитятся в репозиторий**: бинарник в
git-истории остаётся там навсегда и не удаляется вместе с файлом.

## Как приложение их получает

Адрес и контрольная сумма лежат в документе `config/app` (Firestore), откуда
приложение уже читает данные об обновлениях. В коде зашит запасной адрес.

Благодаря этому хостинг можно сменить, не выпуская новую версию приложения:
достаточно поправить одну строку в конфиге.

⚠️ **Приложение обязано проверять SHA-256 после скачивания.** Повреждённый или
недокачанный файл whisper.cpp не отвергнет — он уронит нативную часть.
Порядок: скачать во временный файл → сверить размер и хеш → только потом
переносить в рабочую папку.
